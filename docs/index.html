Motors & Pumps

Motor Block Port: M1 or M2

Run Motor at Speed

Spins the DC motor connected to port 1 (M1) or port 2 (M2) in Forward or Reverse with a speed percentage from 0% to 100%.

Motor Rotate M1 speed 100% direction Forward
MicroPython 
from uqtpy.actuators.motor import Motor

# Initialize motor on port 1 (M1)
motor1 = Motor(port=1)

# Run motor forward at 100% speed
motor1.speed(value=100, direction=1)
Motor Block Port: M1 or M2

Stop Motor

Smoothly stops the motor by setting PWM output to zero.

Motor Stop M1
MicroPython 
# Stop the motor immediately
motor1.stop()
Pump Block Port: P1 or P2

Water Pump Motor

Turns on the submersible water pump at the specified flow speed (0% to 100%). Ideal for automated plant watering systems.

Pump Run Pump P1 speed 80%
MicroPython 
from uqtpy.actuators.pumpmotor import PumpMotor

pump = PumpMotor(port=1)
pump.speed(value=80)  # Run pump at 80%

Servo Motors

Servo Block RJ Port: 1–5

Rotate Servo to Angle

Positions the servo arm precisely at any angle between 0° and 180°. Perfect for robotic arms, steering, and grippers.

Servo Rotate servo on Port 1 to 90°
MicroPython 
from uqtpy.actuators.servo import Servo

servo1 = Servo(port=1)
servo1.rotate(degree=90)  # Set to 90 degrees
Servo Block RJ Port: 1–5

Servo Sweep Motion

Sweeps smoothly back and forth between a starting angle and stopping angle.

Servo Sweep servo Port 1 from 0° to 180°
MicroPython 
# Smooth sweep from 0 to 180 degrees
servo1.sweep(start_angle=0, stop_angle=180)

Lights, Sound & Display

Buzzer Block Built-in: GPIO 4

Play Buzzer Tones

Plays beeps, alarms, and musical notes using the on-board piezo buzzer or an external buzzer module.

Buzzer Beep 1000 Hz for 200 ms
MicroPython 
from uqtpy.actuators.buzzer import Buzzer

buzzer = Buzzer()  # Uses onboard GPIO 4
buzzer.beep(freq=1000, duration=200)
buzzer.stop()
ARGB Block Built-in: GPIO 15

Rainbow & Colored NeoPixels

Controls the 4 addressable RGB LEDs on the QtPi Veda board. Set any color using Red, Green, and Blue values (0–255), or trigger animated rainbow effects.

ARGB Set all LEDs to Red (255, 0, 0)
MicroPython 
from uqtpy.actuators.argb import ARGB

argb = ARGB(pin=15, num_leds=4)
argb.fill(255, 0, 0)  # Fill all red
argb.rainbow()       # Play rainbow animation
OLED Block Port: I2C (SDA 21, SCL 22)

OLED Screen Text & Graphics

Displays text, sensor readings, and status messages on the 128x64 OLED display over the shared I2C bus.

OLED Print "Hello QtPi!" at (0, 0)
MicroPython 
from uqtpy.actuators.oled import OLED

display = OLED()
display.clear()
display.text("Hello QtPi!", 0, 0)
display.show()
LED Block RJ Port: 1–5

Single LED Indicator

Turns an external single-color LED module ON, OFF, or toggles its state.

LED Turn LED on Port 2 ON
MicroPython 
from uqtpy.actuators.led import LED

led = LED(port=2)
led.on()
led.off()

Sensors

Ultrasonic Block RJ Port: 1–5

Ultrasonic Distance Sensor

Measures distance to an obstacle in centimeters (cm) by sending sonic pulses and timing their echo. Range: 2 cm to 400 cm.

Distance Read distance in cm from Port 3
MicroPython 
from uqtpy.sensors.ultrasonic import Ultrasonic

sonar = Ultrasonic(port=3)
distance_cm = sonar.distance()
print("Distance:", distance_cm)
Infrared Block RJ Port: 1–5

Infrared (IR) Obstacle & Line Sensor

Detects nearby objects or lines on the ground for line-following robots. Returns 0 when an object is detected, or analog reflectivity values.

IR Sensor Is obstacle detected on Port 1?
MicroPython 
from uqtpy.sensors.ir import IR

ir_sensor = IR(port=1)
# Returns 0 when obstacle detected, 1 when clear
detected = (ir_sensor.read_digital() == 0)
LDR Block RJ Port: 1–5

LDR Light Intensity Sensor

Reads ambient light levels around your robot. Higher values indicate bright ambient lighting, while lower values mean darkness.

Light Read light level on Port 2
MicroPython 
from uqtpy.sensors.ldr import LDR

light_sensor = LDR(port=2)
light_level = light_sensor.read()
Gyro Block Port: I2C (SDA 21, SCL 22)

MPU6050 Motion & Gyroscope

6-axis motion tracking sensor. Reads tilt, roll, pitch, and acceleration along X, Y, and Z axes for balance robots and gesture controls.

MPU6050 Get Tilt / Acceleration X
MicroPython 
from uqtpy.sensors.mpu6050 import MPU6050

mpu = MPU6050()
accel = mpu.get_accel()  # Returns {'x': ..., 'y': ..., 'z': ...}
x_accel = accel['x']
Soil Block RJ Port: 1–5

Soil Moisture & Temperature

Monitors moisture in soil and ambient temperature for smart agriculture and automated gardening projects.

Moisture Read moisture level from Port 4
MicroPython 
from uqtpy.sensors.moisture import Moisture

moisture_sensor = Moisture(port=4)
moisture_val = moisture_sensor.read()
Switch Block RJ Port: 1–5

Mechanical Limit Switch

Detects physical touch or collision. Perfect as a bumper sensor or homing switch for 3D printer and robotic axes.

Switch Is Switch on Port 5 pressed?
MicroPython 
from uqtpy.sensors.limitswitch import LimitSwitch

switch = LimitSwitch(port=5)
if switch.is_pressed():
    print("Bumper hit!")

Bluetooth & App Inventor Connection

BLE Service Built-in: ESP32 BLE

QtBLE Wireless Smartphone Control

Starts the standard QtPi Bluetooth Low Energy GATT service. Enables students to connect mobile apps created with MIT App Inventor / Code2Play to control motors and stream sensor telemetry in real time.

Bluetooth Start BLE Service as "QtPi_Bot"
MicroPython 
from uqtpy.comm.ble.service import QtBLE

ble = QtBLE()
ble.start(name="QtPi_Bot")  # Advertises to App Inventor
